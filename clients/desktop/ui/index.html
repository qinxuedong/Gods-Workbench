关于与连接状态

已有本地账户？

桌面端不会自动接管或创建第二个所有者。若提示需要人工认领，请在受控终端使用 python -m gw.core.local_accounts_cli --mode prod trusted-claim，通过原账户或管理员认证完成认领；密码登录始终可用。

受信本机自动进入要求账户目录与设备密钥仅限当前用户、SYSTEM 与 Administrators 访问。权限不合格时只会关闭自动进入，不会放宽权限，也不会导出密钥。

NAS 服务需要开放端口 2077。远程连接只按能力契约放行，且永不注入本机一次性票据。
