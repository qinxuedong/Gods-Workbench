备用启动方式

若安装壳无法拉起本机服务，可在神工坊项目根目录双击运行 start.bat，或在终端执行 python run.py --prod，然后重新打开桌面端。

已有本机账户时，受信自动进入依赖当前用户、SYSTEM 与 Administrators 独占的账户目录权限；权限不合格时只关闭自动进入，不会放宽权限或导出密钥。密码登录始终可用。

客户端仅保存服务器地址与主题偏好，不保存模型 API 密钥、设备密钥或本机票据。
