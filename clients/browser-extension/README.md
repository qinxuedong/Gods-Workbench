# 神工坊素材收集扩展（Chrome / Edge，MV3）

把网页上的图片与视频直链一键收入**本机**神工坊素材库（`collect_inbox`）。右键菜单为主入口，
`Ctrl + 右键` 为默认开启、可在选项页关闭的快捷方式。

## 安装

1. 在浏览器地址栏打开扩展管理页（Chrome：`chrome://extensions`；Edge：`edge://extensions`）。
2. 打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录 `clients/browser-extension`。
4. 先启动工作台（默认 `http://127.0.0.1:2077`）并登录，再在扩展选项页点「立即配对」。

本扩展不打包任何图标、字体或第三方脚本，全部逻辑为仓库内纯原生 JavaScript。

## 使用

| 入口 | 行为 |
| --- | --- |
| 右键菜单「收入神工坊：收藏这张图片 / 该视频地址 / 链接目标 / 本页地址」 | 把对应地址提交给本机工作台收集 |
| `Ctrl + 右键`（默认开启） | 不展开浏览器菜单，直接按光标下的图片 / 视频 / 链接 / 背景图收集 |

收集结果通过页面右下角提示、扩展图标徽标（`✓` / `!`）与选项页「最近一次收集」反馈；
延迟与失败原因同时记入 `chrome.storage.local` 的最近 20 条历史，便于定位。

## 行为契约

- 只接受 `http(s)` 地址；`blob:`、`data:`、`mediasource:`（MSE）、DRM 内容一律**明确失败**并给出中文原因，不静默丢弃。
- 页面与流的支持度取决于工作台侧 `gw/asset_registry/collector.py`：直链可直取，HLS/DASH/站点页面需工作台安装 `yt-dlp`。
- 内容相同的素材由工作台按 SHA-256 去重，重复收集只追加来源，不产生重复文件。
- 收集文件一律写入独立的 `registry_uploads/collect_inbox/`，**绝不写入用户已有素材源目录**。

## 安全与隐私边界

- **零模型密钥**：扩展不保存任何商业模型 API Key，也不读取工作台凭据；测试对源码做禁止模式扫描。
- **端点仅本机**：`host_permissions` 只包含 `http://127.0.0.1:2077/*` 与 `http://localhost:2077/*`；
  端点校验拒绝非回环主机与非 2077 端口。
- **网络留在工作台源**：工作台会话 Cookie 为 `SameSite=strict`，`chrome-extension://` 属跨站带不上会话，
  因此配对与收集请求由只注入工作台源的 `content/app-bridge.js` 在**页面同源**上下文中发起；
  service worker 只做编排，不接触 Cookie 原文。
- **配对令牌**：`POST /api/asset-collect/pair` 取得的一次性令牌存在 `chrome.storage.session`（浏览器关闭即失效），
  工作台侧有效期 1 小时，过期自动重配对。
- 除工作台端点外，扩展不向任何主机发起请求。

## 已知限制

- 仅支持工作台默认端口 2077 与本机回环地址；NAS / 局域网部署请在工作台内粘贴 URL 收集。
- 工作台未打开时首次收集需拉起标签页，此时耗时可能超过 3s；正常（工作台已开）路径由
  「令牌缓存 + 页面同源提交 + 2500ms 轮询预算」保证扩展侧 ≤3s。
- `Ctrl + 右键` 在部分站点或 macOS 上可能与系统菜单冲突，冲突时关闭该快捷方式、改用右键菜单。
- 需要登录或防盗链的图片可能取不到原始地址，此时请在工作台内粘贴页面 URL。

## 版权与使用范围

仅用于个人素材收集；不规避任何 DRM 或付费墙，不做批量爬取，不用于再分发受版权保护的内容。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | MV3 清单：权限、回环 host、content script 装配顺序 |
| `background.js` | 右键菜单、配对令牌缓存、工作台标签页发现/拉起、延迟日志与徽标 |
| `src/target-resolver.js` | 目标地址解析（`srcset` 最大项、背景图、视频海报、内部地址错误码），纯逻辑 |
| `src/collect-client.js` | 收集接口客户端（配对 / 提交 / 轮询 / 错误码文案），端点只允许本机 2077 |
| `content/app-bridge.js` | 只注入工作台源，在页面同源上下文完成配对与提交 |
| `content/collect-shortcut.js` | `Ctrl + 右键` 快捷收集与页面内提示，自身不发网络请求 |
| `options.html` / `options.js` | 端点二选一、快捷方式开关、手动配对、最近一次收集耗时 |

契约测试：`tests/frontend/mvp1-t8b-extension.test.mjs`（已登记 `tests/frontend/node-files.txt`）。
测试用 `node:vm` 加载上述出货文件本体，断言清单权限边界、地址解析、HTTP 契约与延迟日志。
