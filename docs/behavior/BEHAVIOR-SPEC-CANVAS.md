# 神工画布统合行为规范 (Canvas Unified Behavior Specification)

- **规范代号**：`BEHAVIOR-SPEC-CANVAS`（GNS-2026 / CBS-2026）
- **状态**：CURRENT / APPROVED_BASELINE
- **适用范围**：神工画布（God Canvas）与智能画布（Smart Canvas）的统合交互、视口拓扑、多模态节点、四大基础 AI 生成管线、资产中枢流转、手势系统、持久化与并发状态机
- **归属**：`docs/behavior/BEHAVIOR-SPEC-CANVAS.md`（单一真源）
- **发布状态**：**RELEASED_INTERNAL_CORE**

---

## 1. 范围与第一性原理

本规范定义神工画布全生命周期的可观察行为与响应语义，是系统业务实现、前后端契约与自动化验收的唯一合法基准。

画布在神工坊视听生产体系中承担三大定位：
1. **上游调度台**：承接文学剧本与文字分镜，将其具象化为视听资产要素空间编排；
2. **中游精修台**：为生成的图像与视频资产提供涂抹遮罩局部重绘（Inpaint）、外绘扩图（Outpaint）、高清放大（Upscale）、抽帧截取等精修交互；
3. **下游检验台**：承接 ComfyUI / RunningHub 异步生成成果，提供多候选盲测对比与一键定稿入库。

## 2. 核心对象与稳定命名矩阵 (GNS-2026)

全链路严格采用统一长 ID，禁止短别名：

- **画布标识**：`canvas_id`（如 `cv-0001`）
- **节点标识**：`entity_id`（如 `nd-0001`）
- **连线标识**：`connection_id`（如 `conn-0001`）
- **端口标识**：`port_id`（如 `in-0`, `out-0`）
- **项目标识**：`project_id`（如 `prj-0001`）
- **资产标识**：`asset_id`（如 `ast-0001`）
- **异步任务标识**：`job_id`（如 `job-0001`）
- **工作流标识**：`workflow_id`（如 `wf-0001`）
- **提示词条目标识**：`pitem_id`（如 `pitem_0001`）

影视工业命名规范：
- 分集 `EPxx`（超长篇 `EP001`）、场次 `SCxx`、镜头 `SHxxx`、版本三位补零 `v001`。
- 物理存储名（纯 ASCII 稳定 ID）与表层业务语义导出名双层解耦映射。

## 3. 三大基准画布体系

系统沿用并支持三大基准画布模式，支持平滑归宿流转：

### 3.1 项目画布 (Project Canvas)
- 强绑定 `project_id`，继承项目排期（`start_at` / `due_at`）、生产阶段与状态；
- 支持**多属性子画布（Sub-Canvases）**架构，包含：
  1. **分镜叙事子画布**：镜头组与场次泳道主线；
  2. **角色定设子画布**：人物三视图、服饰道具与表情库；
  3. **资产管理子画布**：场景空镜、三维模型等物料管理；
  4. **草稿演练子画布**：项目内部实验试错沙盒；
  5. **专属参考子画布**：特定色彩与影调参考板。

### 3.2 智能画布 (Smart Canvas)
- 独立单机自由创作空间，生成资产暂存公共资产库；
- 提供一键“归属至项目”能力，可整体作为新子画布迁入指定项目，或将选中节点合并入库。

### 3.3 参考画布 (Reference Canvas)
- 直连资产库全局参考体系，专用于视觉对标、比稿比对与临时发散；定稿后一键“选定入项”。

## 4. 四大基础 AI 生成流水线与多模态节点

画布原生支持四大基础 AI 生成范式：

1. **文生图 (Text-to-Image / t2i)**：
   文本节点（Prompt/模板） $\rightarrow$ 高级工具节点（选定工作流模板） $\rightarrow$ 图像节点（自动登记资产）。
2. **图生图 (Image-to-Image / i2i - 精修核心)**：
   图像节点（原图 + Mask 涂抹遮罩） + 文本节点（修改提示词） $\rightarrow$ 高级工具节点 $\rightarrow$ 衍生图像节点（保留版本链）。
3. **文生视频 (Text-to-Video / t2v)**：
   文本节点（分镜与运镜提示词） $\rightarrow$ 高级工具节点（Wan2.1 / Kling 等模板） $\rightarrow$ 视频节点（MP4，逐帧步进）。
4. **图生视频 (Image-to-Video / i2v)**：
   图像节点（首帧关键帧/角色参考） + 文本节点（动作运镜描述） $\rightarrow$ 高级工具节点 $\rightarrow$ 视频节点。

### 节点类型与交互能力
- **文本节点 (`text_prompt` / `text_dialogue` / `text_memo`)**：
  - 直连资产中心提示词库（`gw/prompt_library`：`plib` / `pcat` / `pitem`），一键拉取模板；
  - 台词对白节点标注角色与情绪，自动估算朗读预估时长。
- **图片节点 (`image_asset`) —— 精修台**：
  - 本地图片拖拽/粘贴上传，EXIF/生成参数回读；
  - 精修工具套件：画笔涂抹遮罩（Mask）、边缘拉伸外绘（Outpaint）、高清放大（Upscale）、取色吸管。
- **视频节点 (`video_asset`)**：
  - 原生 HTML5 硬件加速无黑屏播放；
  - 键盘左右键逐帧微调（Frame Stepping）；
  - 出入点切片标记（In/Out Trim）；
  - 一键截取当前帧生成新图片节点（Keyframe Extractor）。
- **音频节点 (`audio_asset`)**：
  - Canvas 绘制波形图（Waveform），时间码对齐打点，音画同步预览。
- **高级黑盒工具节点 (`workflow_tool`)**：
  - 下拉选择已配置的 ComfyUI / RunningHub 工作流；
  - 动态参数提取：根据工作流已标记入参，动态在卡片上加载输入槽位；
  - 点击执行派发任务，返回 `202 Accepted` 与 `job_id`，刷新页面后任务进度无损恢复。
- **结构容器节点 (`shot_frame` / `scene_swimlane`)**：
  - 镜头组容器：组合“台词+参考图+生成画面+配音”，具备 16:9 / 9:16 / 2.39:1 画幅遮罩；
  - 场次泳道：按剧本场次时序排列镜头。

## 5. 用户可观察行为与快捷手势规范

### 5.1 画布物理规则：防堆叠碰撞机制
- 画布元素**严禁堆叠遮挡**；
- 节点移动放置或批量生成时，计算包围盒，自动保持至少 `32px` 物理间距；
- 靠近其他节点时产生柔性排斥与金色吸附对齐标尺。

### 5.2 视口操作基础
- **鼠标左键**：点选、框选、长按拖动选中节点；
- **鼠标中键长按**：抓手（平移视口）；
- **鼠标滚轮**：以光标为中心平滑缩放（钳制范围：20% ~ 300%）。

### 5.3 居中宽幅 Spotlight 节点创建菜单 (Tab / 右键)
- 按 `Tab` 键或空白处点击鼠标右键，视口靠上居中弹出宽幅面板（约 720px）：
  1. 顶部快捷搜索框；
  2. 搜索下方 Top 10 高频节点快捷栏（基于本地频次统计，数字键秒建）；
  3. 下方展开全部节点分类树，点击即建；
  4. 选中联动等距连线：若已有选中节点，创建新节点自动在其右侧等距生成并自动建立连线。

### 5.4 金色刀光斩切手势系统 (Gold Cutting Trail)
- **节点斩切删除**：按住 `Ctrl` 键，鼠标左键自节点左上方划向右下方；
- **连线斩断断开**：按住 `Ctrl` 键，鼠标右键划过任意连线路径；
- **视觉反馈**：鼠标划动期间以 60fps 实时渲染金色粒子刀光轨迹（`#dfc384` 辉光），松手瞬间目标元素微缩淡出；
- 基础备用：选中元素按 `Delete` 或 `Backspace` 键直接删除。

### 5.5 节点拖拽替换 (Drag-and-Drop Replacement)
- 将兼容输入输出的节点 A 拖放到已连线的节点 B 上；
- 弹出轻量气泡确认后替换 B，并自动继承重连节点 B 的所有连线。

### 5.6 快捷连线与端口放大镜
- `Shift` + 鼠标左键长按拖拽：直接连向目标第 1 输入接口；
- `Shift` + 鼠标右键长按拖拽：直接连向目标第 2 输入接口；
- 端口放大镜：连线靠近多端口卡片瞬间，输入端口自动放大 200% 弹出气泡选择区，精准磁吸。

### 5.7 分组管理
- `Ctrl + G`：多选节点打组（创建镜头组容器）；
- `Shift + G`：解散选中分组。

## 6. 统一资产库双向流转闭环

1. **规则 A（项目内生成）**：
   在项目画布发起的任何 AI 生成产物，自动继承 `project_id`，生成稳定 `asset_id`，向资产库自动注册并写入画布来源追溯元数据（`source_type: "canvas"`, `source_canvas_id`, `source_node_id`）。
2. **规则 B（资产拖入项目）**：
   从资产库拖入项目画布的资产，自动与当前项目建立关联引用（Relation），保留原 `asset_id`，不产生物理重复副本。

## 7. 数据架构、持久化与状态码语义

### 7.1 标准 JSON 拓扑格式
拓扑完全基于标准 JSON 序列化，包含 `canvas_id`、`project_id`、`version`、`viewport`、`nodes`、`connections`、`references`，与黄金夹具 `canvas-workflow-minimal.json` 保持严格一致。

### 7.2 持久化与 CAS 规范 (`gw.core.storage`)
- 元数据落盘至 `data_root() / "canvases_registry.json"`；
- 拓扑文件落盘至 `data_root() / "canvases" / "{canvas_id}.json"`；
- 写入强制携带 `expected_version`（CAS），冲突时明确返回 HTTP 409（`CANVAS_VERSION_CONFLICT`），禁止静默覆盖；
- 单实例使用临时文件原子替换保证落盘一致性。

### 7.3 HTTP 状态码语义
- `200 OK` / `201 Created`：同步请求成功；
- `202 Accepted`：异步任务受理，必须返回稳定 `job_id` 与 `poll_hint`；
- `401 Unauthorized`：未认证会话，禁止一切写入；
- `403 Forbidden`：项目或画布权限不足，只读降级；
- `404 Not Found`：画布、节点或任务不存在（越权资源统一返回 404 隐藏）；
- `409 Conflict`：CAS 版本冲突。

---

## 8. 门禁验收标准

1. 并发写入同一画布时稳定触发并正确处理 409；
2. 导入非法或损坏的拓扑 JSON 严格拒绝并返回结构化 400 错误；
3. 纯 ASCII 路径与零临时标记通过治理脚本扫描；
4. 异步 AI 生成派发返回 202 后刷新页面，任务状态与产物绑定无损恢复。
