# 神工画布行为规范 (Canvas Behavior Specification)

- **状态**：CURRENT / FROZEN_BASELINE
- **适用范围**：神工画布（God Canvas）交互、拓扑编辑、序列化与状态机
- **约束**：无旧源码复制、无旧变量/DOM 复制、零用户数据；严格贯彻 CAS 版本控制与统一错误语义
- **发布状态**：**NOT AUTHORIZED FOR PUBLIC DISTRIBUTION**

## 1. 范围

本规范定义“普通画布”的外部行为与错误语义，不涉及实现代码。

覆盖目标：

- 视口平移与缩放
- 节点选择、拖拽、删除、分组、连线
- 工作流 JSON / `.godmap` 的读写
- 稳定 ID 与 CAS 冲突处理
- 任务与资产引用
- `401/403/409/202` 响应语义

## 2. 核心对象

- 画布：`canvas_id`，持有节点集合与连线集合
- 节点：`entity_id`（稳定 ID）
- 连接：`connection_id`（稳定 ID 或可重建有向边键）
- 资产引用：`asset_id`
- 任务引用：`job_id`

## 3. 用户可观察行为

### 3.1 视口交互

1. 支持鼠标/触控平移。
2. 支持滚轮或快捷键缩放，缩放中心应接近光标焦点。
3. 支持缩放上下限，超限时钳制。

### 3.2 节点与连线

1. 单选、多选、框选必须一致可预期。
2. 可拖拽节点并实时更新连线路径。
3. 删除节点时，关联连线与悬挂引用必须同步清理。
4. 支持将多节点收编到分组，分组可整体移动。
5. 连线创建需校验端口方向与类型兼容性。

### 3.3 持久化与冲突

1. 每次写入带 `expected_version`（CAS）。
2. 写入成功后刷新本地版本。
3. 命中冲突返回 `409`，前端进入“冲突提示 + 拉取最新 + 再合并”流程。

### 3.4 JSON / `.godmap` 读写

1. 支持导出为 JSON，字段完整且可复现拓扑。
2. 支持导入 JSON / `.godmap`。
3. 导入必须进行结构校验：节点、连线、引用关系缺失时拒绝写入。
4. 导入后产生的新节点应分配新的稳定 ID，避免与现有 ID 冲突。

### 3.5 任务与资产引用

1. 节点允许绑定任务与资产引用。
2. 删除或失效引用时，应在节点上呈现可见失效状态。
3. 资产/任务读取失败不可阻断整个画布渲染。

## 4. 状态码语义

- `202 Accepted`：后端接受异步处理；前端保持“处理中”并可轮询/续查。
- `401 Unauthorized`：会话失效或未认证；禁止继续写操作。
- `403 Forbidden`：无当前项目或画布写权限；只读降级。
- `409 Conflict`：版本冲突；提示用户刷新并解决并发差异。

## 5. 门禁验收

1. 同一画布并发写入能稳定复现并处理 `409`。
2. 导入非法 `.godmap` 文件时拒绝写入并返回结构化错误。
3. 认证失效后所有写操作被拒绝，不产生隐式本地“成功”。
4. 任务异步返回 `202` 时前端保持可恢复进度，而非立即失败。
