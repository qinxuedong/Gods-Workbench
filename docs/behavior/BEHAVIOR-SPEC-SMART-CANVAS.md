# 智能画布行为规范 (Smart Canvas Behavior Specification)

- **状态**：CURRENT / FROZEN_BASELINE
- **适用范围**：智能画布（Smart Canvas）异步任务驱动、级联执行、状态续查与资产绑定
- **约束**：无旧源码复制、无旧变量/DOM 复制、零用户数据；普通拓扑与智能编排统一归属于 `god-canvas`
- **发布状态**：**NOT AUTHORIZED FOR PUBLIC DISTRIBUTION**

## 1. 范围

本规范定义“智能画布”行为。与普通画布共享基础交互，但额外覆盖：

- 多步骤任务编排与异步执行
- 任务状态续查
- 资产库引用与批量输入
- 冲突与权限语义的一致化

## 2. 智能画布附加行为

### 2.1 任务驱动节点

1. 节点可触发异步任务，任务与节点建立可追溯关联（`job_id` ↔ `entity_id`）。
2. 异步受理返回 `202` 时，节点进入排队/运行中状态。
3. 任务完成后，输出资产自动绑定到对应节点引用。

### 2.2 级联执行与中断

1. 支持从选中节点启动级联执行路径。
2. 中断请求应在可控边界生效，不得破坏已提交产物的一致性。
3. 级联执行失败应定位到失败节点，不应整体吞错。

### 2.3 资产引用与批量输入

1. 支持本地/远端资产的统一引用模型。
2. 批量输入数量超限时返回显式错误，不隐式截断。
3. 失效资产引用必须可见，并提供替换入口。

### 2.4 冲突与恢复

1. 与普通画布共用 `expected_version` CAS 语义。
2. `409` 后可执行“刷新远端版本并重放本地未提交变更”。
3. 页面刷新后应能恢复最近一次可保存状态。

## 3. 状态码语义

- `202 Accepted`：异步任务已受理，需后续查询结果。
- `401 Unauthorized`：身份失效，禁止任务发起与画布写入。
- `403 Forbidden`：权限不足，仅保留只读能力。
- `409 Conflict`：并发版本冲突，需拉取最新并重试。

## 4. 验收语义

1. 同步编辑与智能任务并行时，不得破坏拓扑一致性。
2. 任务返回 `202` 后 UI 可追踪，不丢失任务关联。
3. 任务失败、鉴权失败、冲突失败均需具备可区分错误提示。
4. 资产引用跨节点复用时，删除任一节点不应破坏其他节点引用。
