# 通用产物下载与清理契约

## 归属和权限
- GET /api/download-output 与 GET /api/storage-files需要认证；POST /api/storage-files/delete需要编辑权限。匿名401，只读删除403。
- 通用接口只准入数据根下ai_uploads、media_output、registry_uploads、local_assets四个固定目录中的普通产物文件。根JSON/SQLite、未知目录、受项目ACL保护的视频目录均403；合法目录中的用户JSON附件可作为产物。
- path必须是相对数据根的安全路径。绝对路径、UNC、盘符、ADS、点段、空段、Windows设备名/尾部空格或点拒绝；不得以“文件尚不存在”为由放行未知目录。不存在的合法文件下载404、删除列为skipped。
- 检查原始全部组件的符号链接/Windows重解析点，四个准入目录自身及父目录也不得绕过；resolve后必须仍属于原来的命名空间。列表先检查再遍历，asset_id推导候选及响应读取前也使用同一检查。
- 该边界隔离服务内部状态，不代表合法产物目录内全面多租户ACL；视频始终走专用项目鉴权路由。

## 删除和真实失败
- 批量请求先完整预检，任何非法输入都拒绝整批且未发生删除。
- 执行前再次校验；执行期间磁盘失败或对象替换不冒充成功。返回deleted/skipped/failed、count=真实删除数量，failed非空时data_status=partial；错误代码不泄漏绝对路径和原始OS错误。
- 不承诺文件系统事务或对抗具有本机同账号文件系统控制权限的所有TOCTOU攻击；不删除目录，不递归删除，不跟随链接。

## 本地验证边界
- 测试全部使用临时数据根，禁止读取/删除真实团队或认证数据库。
- 回归含四目录真实下载和删除、内部状态/路径别名拒绝、混合预检与真实Windows Junction三种布局；单独文件符号链接受当前Windows账户权限限制时必须如实skip，不能冒称该夹具通过。
