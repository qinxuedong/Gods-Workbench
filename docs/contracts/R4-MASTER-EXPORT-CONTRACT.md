# R4-A Master Export 与时间线热替换契约

## 范围

本文定义 C15-T1 的时间线图片片段升级为视频片段时必须保持的编辑状态，以及后续母带导出消费时间线数据时的约束。该变更只处理时间线清单，不提交渲染任务、不调用外部模型或媒体供应商。

## 时间线图片到视频原位替换

替换以稳定的 `shot_id` 定位现有片段，并在同一轨道、同一位置更新媒体引用：

- 将 `asset_id` 改为经审核选中的视频资产 ID。
- 将 `media_type` 设为 `video`，并将 `overrides.src` 指向视频源。
- 保留片段的 `shot_id`、`at`、`duration`、轨道顺序和所有其他片段。
- 保留 `overrides` 中除 `src` 外的全部键值，包括调色 LUT、裁切/缩放、转场和其他人工编辑。
- 纯变换不得修改输入对象。

服务必须要求调用方提供 `expected_version`。持久化使用现有 timeline manifest CAS：版本匹配时写入一次并递增版本；版本过期时返回 `409 VERSION_CONFLICT`，不能覆盖并发编辑。

## 母带导出输入

导出器消费 `timeline_manifest` 中每个片段的时间位置、时长、媒体引用和 overrides。导出实现应将保留的人工属性映射到媒体滤镜和时间线合成参数；不得在导出准备过程中改写原始时间线清单。

## 验收证据边界

C15-AC1 的本地契约测试覆盖片段原位替换、overrides 保留、输入不变、持久化 API JSON 和 CAS 版本递增。测试不证明真实视频文件存在、播放成功或母带已经渲染；这些属于后续成片导出验收。
