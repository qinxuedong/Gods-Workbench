# Gods-Workbench 设计系统指南

- **状态**：CURRENT
- **适用范围**：`web/` 原生 HTML、JavaScript、CSS 及其可复用组件
- **权威顺序**：`AGENTS.md` 的工程与洁净室约束 > 用户2026-10-12按钮范围与状态裁决及 `.local/docs/design/按钮设计标准/{DESIGN.md,code.html,screen.png}` 的按钮视觉真源 > 本指南与项目实现 > 页面局部样式
- **目的**：保留对未来项目仍有效的视觉、交互和无障碍规则；不复制历史设计稿、截图、提示词或旧页面叙述。

## 1. 设计原则

1. **硬件化但不伪造业务状态**：黑金硬件质感用于层级、焦点和操作反馈；颜色、灯效、仪表和动画不能代替后端真实状态。
2. **原生优先**：页面使用原生 HTML5、现代 JavaScript 和 CSS；不引入 React、Vue、Webpack、Vite 或新的构建链。
3. **分层真源**：项目全局 token、字阶、间距和交互规则在本指南与实现中维护；按钮视觉以指定本地原稿为真源，页面专项文档不得另建全局 token。
4. **可验证**：每个视觉状态必须能由文字、图标或可访问名称复述；设计说明不能替代契约测试、浏览器验证或生产验收。

## 2. 视觉 token

### 2.1 表面与品牌

| Token | 值 | 用途 |
| :--- | :--- | :--- |
| `surface` | `#090a0d` | 页面主表面 |
| `surface-deep` | `#040507` | 凹槽、输入区和低层面板 |
| `surface-raised` | `#141720` | 卡片、弹窗和高层面板 |
| `primary` | `#dfc384` | 主品牌香槟金、焦点和主要动作 |
| `primary-soft` | `#fae2c8` | 高亮文本和主色容器 |
| `secondary` | `#eddab3` | 次级强调 |
| `compute` | `#38bdf8` | 算力、进行中或当前项 |

### 2.2 语义色

- `emerald`：在线、完成、已确认；
- `cyan`：当前、计算、信息；
- `amber`：排队、注意、待处理；
- `rose`：失败、拒绝、高负荷；
- `slate`：次要、归档、不可用。

语义色必须同时配合文字、图标或状态标签，不得只用颜色传递信息。

## 3. 字体、字阶与布局

- 字体仅使用 `web/vendor/fonts/SourceHanSansCN-{Bold,Medium,Normal}.otf` 与系统原生回退栈；不得新增字体或运行时外链字体 CDN。
- 页面级字阶固定为：主标题 `16px/24px/700`、栏目/卡片标题 `14px/22px/500`、正文与输入 `14px/22px`、元数据/辅助文字 `12px/18px/400`。2026-10-11 用户确认保留既有标题字阶；按钮文字采用 BUTTON-SYSTEM-SPEC.md 的尺寸矩阵，不再继承正文控件字号。
- 标题和正文保持足够对比度与可读行高；不要用微小文字承载关键操作或错误说明。
- 标准外边距 `24px`，区块间距 `32px`，可扫描列表行高 `56px`；移动端允许缩小外边距，但不得破坏触控目标和阅读顺序。
- 倒角、金属渐变、局部阴影和 UV 表只表达控件层级，不表达权限、任务完成或数据可信度。

## 4. 组件与交互

- **按键与控制组件（Buttons）**：遵循 [BUTTON-SYSTEM-SPEC.md](BUTTON-SYSTEM-SPEC.md) 的项目实现映射，并以指定本地原稿 `.local/docs/design/按钮设计标准/{DESIGN.md,code.html,screen.png}` 为视觉依据；具体按钮以 `code.html` 的最终计算样式为准，其中最后加载的样式表 `custom-refined-overrides` 覆盖前面的演示 CSS；内联 `style` 与 `!important` 仍按 CSS 优先级核对。八类分别为 Pill、Tactile、Round Push、Segmented、Rocker、Slide Toggle、Launch Orb、Dial；原稿的第08节是实现速查，不是按键族系。保留原稿材质差异和深工控暗绯红（`#8C0000`）危险态，不把示例场景转成业务授权。已确认页面标题16/14px、既有AI微球32px；Dial目前没有产品消费者，不因进入设计字典而增加功能。字体、无障碍、减少动效和禁用状态仍服从仓库工程约束。
- **按钮使用与状态**：2026-10-12用户纠正要求拟物发光胶囊仅固定顶栏10个导航使用，其他位置使用常规按钮及真实选择态。金色主按钮默认、悬浮、按压均保持金色背景和深色刻字；悬浮上移2px并提亮，按压下移2.5px、缩放0.97并形成内凹阴影，不能被常规黑色按压态覆盖。
- **顶栏**：保持稳定高度和明确的页面标题、身份入口、状态入口；身份状态来自真实认证状态。
- **微球尺寸例外**：原稿有 `48px` 大样例；输入框行内示例的实际 HTML 是 `w-8 h-8`，即 `32px`，其“30px”注释不作为尺寸依据。2026-10-11 用户确认全站既有 AI 微球入口保留 `32px`；材质、状态、焦点与动效降级仍按新按钮规范验收。规范族系是设计字典，不授权新增未实现的业务动作。
- **面板/卡片**：使用清晰的标题、边界和层级；不要用装饰遮挡正文或操作。
- **表单**：每个输入有可见标签、键盘顺序、错误说明和提交中的禁用状态；错误信息使用标准接口错误包转换后的用户可读文本。
- **弹窗**：打开后焦点可达，关闭方式明确，不能把关键流程藏在不可访问的悬浮层中。
- **导航**：保留浏览器后退、深链上下文和显式失败状态；不得用空白 200 页面或无限重定向掩盖能力缺失。
- **状态反馈**：支持 `prefers-reduced-motion`；动画只强化状态，不是状态本身。

## 5. 无障碍与响应式门禁

- 所有可操作元素可用键盘访问，并有可见焦点；图标按钮必须有 `aria-label` 或等效可访问名称。
- 颜色对比、错误提示、成功提示和禁用状态不能只依赖颜色或动效。
- 支持窄屏单列、文字放大、强制颜色模式和减少动态效果；布局不能依赖全局 `zoom`。
- 真实浏览器验证至少覆盖键盘路径、弹窗焦点、表单错误和窄屏关键入口。

- 不提交图片、截图、音视频、压缩包或未授权字体；本地字体只允许 AGENTS 白名单三件套。

- 设计通过不等于业务验收通过；必须把代码、定向测试、浏览器实测、远程 CI 和生产验收分开记录。
