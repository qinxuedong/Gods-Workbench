# 键盘快捷键使用说明

> **核对日期：2026-11-02**。本文按当前 Web 工作台代码整理，说明键位、页面范围和输入状态限制。桌面容器没有额外的应用级快捷键绑定；浏览器、操作系统和输入法自己的按键不在本文范围内。
>
> **长期维护：**新增、修改或移除快捷键时，同步更新本文；每季度复核一次。下次计划复核：2027-02-02。跟踪票：[QIN-521 / #556](https://github.com/qinxuedong/Gods-Workbench/issues/556)。

## 使用前先看

- 快捷键按当前焦点和打开的页面生效。同一个物理键可能在项目列表、画布列表、制片页和素材预览中执行不同动作。
- 表中的 `Ctrl/⌘` 表示代码同时识别 Windows/Linux 的 Ctrl 与 macOS 的 Command；只写 `Ctrl` 的地方只识别 Ctrl。
- `·`、反引号 `` ` `` 和波浪号 `~` 常位于键盘左上、数字 1 左侧。不同键盘、输入法可能产生不同字符；系统部分页面还会检查物理 `Backquote` 键码。
- 如果按键没有触发预期动作，先退出输入框/文字编辑、关闭浮层，再把焦点放到目标卡片或控件上。也可直接使用页面上的按钮。
- 文本输入和中文输入法组合期间，字符类快捷键会让位给输入；搜索框、编辑器内明确列出的保存/取消动作除外。

## 1. 全局搜索

| 按键 | 作用 | 范围与说明 |
| --- | --- | --- |
| `Ctrl+Space` | 打开工作台搜索 | 只识别 Ctrl；部分输入法会先占用该组合键。 |
| `Ctrl+F` | 打开工作台搜索 | 工作台页面内会接管浏览器查找键；macOS 的 `⌘F` 当前不会触发此功能。 |
| `↑` / `↓` | 在结果中移动选择 | 搜索浮层打开时。 |
| `Enter` | 打开选中结果；Agent 模式下提交输入 | 素材模式没有选中项但有结果时，默认打开第一项。输入法仍在组字时不会提交。 |
| `Esc` | 关闭搜索浮层 | 关闭后焦点返回打开搜索前的控件。 |
| `Tab` / `Shift+Tab` | 在关闭按钮、模式按钮和输入框间移动 | 焦点保持在搜索浮层内。 |

## 2. 列表、卡片与常用控件

工作台中已登记为可导航条目的素材卡、工作流卡、提示词行、画布素材等，在目标条目获得焦点时支持：

| 按键 | 作用 |
| --- | --- |
| `J` / `↓` / `→` | 聚焦同一列表中的下一项 |
| `K` / `↑` / `←` | 聚焦同一列表中的上一项 |
| `Space` | 调用当前条目提供的预览动作；没有预览动作的条目可能不响应 |
| `Tab` / `Shift+Tab` | 按页面顺序移动焦点 |
| `Enter` / `Space` | 激活获得焦点的按钮或键盘按钮 |

列表导航只在识别的条目/作用域内接管方向键；编辑框、文本区域和下拉框继续处理自己的输入。方向键没有被列表消费时仍按页面原有行为执行。

## 3. 首页、项目中心与画布列表

### 首页项目卡

在首页且没有输入框或弹窗获得焦点时，按 `·`、`` ` `` 或键盘左上角的 `Backquote` 键，进入当前活动项目的制片页。没有活动项目时使用页面当前的第一个项目。输入、中文组字、带修饰键的组合以及打开的弹窗会屏蔽该快捷键。

### 项目中心

在项目中心的项目列表中按 `·`、`` ` `` 或 `Backquote`，打开活动项目的影视工坊；没有活动项目时使用列表中的第一个项目。焦点位于输入框、文本区域、下拉框或可编辑内容时不触发。

### 画布卡片

先把焦点放到一张画布卡片上：

| 按键 | 作用 | 条件 |
| --- | --- | --- |
| `Enter` | 打开该画布 | 焦点位于画布卡片。 |
| `Space` | 选中该画布 | 焦点位于画布卡片。 |
| `·` / `` ` `` / `Backquote` | 打开当前选中的画布 | 画布列表没有打开输入、菜单、删除确认、回收站或归档面板。 |
| `Esc` | 关闭画布菜单/新建卡片/删除确认；打开回收站或归档时返回画布列表 | 画布列表页面。 |

## 4. 资产库与图片浏览

### 资产看板和网格

| 按键 | 作用 | 条件 |
| --- | --- | --- |
| `←` / `→` | 切换相邻资产看板 | 焦点位于看板标签。 |
| `Home` / `End` | 切换到第一个/最后一个看板 | 焦点位于看板标签。 |
| `Alt+←` / `Alt+→` | 将当前自定义看板与相邻看板交换顺序 | 焦点位于看板标签；内置「资源库」看板不能移动。 |
| `←` / `→` / `↑` / `↓` | 在资产网格中移动选择并将焦点带到对应卡片 | 资源库或自定义看板处于活动状态，且焦点不在文字编辑框中。 |
| `J` / `K` | 在当前焦点所在的条目列表中前进/后退 | 焦点位于已登记的资产卡或列表项。 |
| `Space` | 打开当前条目提供的预览 | 焦点位于有预览动作的卡片上。 |
| `F` | 真全屏查看当前选中图片/视频（浏览器全屏） | 焦点不在卡片内按钮等交互控件，且选中的是可视素材；`F` 不带 Ctrl/Command/Alt；查看器内 `←` / `→` 切换素材，`F` 或 `Esc` 关闭。 |
| `Enter` | 打开当前选中图片/视频的 Coverflow 轮播 | 焦点不在卡片内按钮等交互控件，且选中的是可视素材。 |
| `Ctrl/⌘+A` | 全选当前资源库或自定义看板素材 | 不在输入或文字编辑状态。 |
| `Esc` | 清除当前批量选择 | 有已选中的批量素材时优先清除选择。 |

### 预览与全屏图片浏览

- 在素材详情中单击 `·`、`` ` ``、`~` 或 `Backquote`，仍会打开/关闭当前素材预览；图像或可编辑文档预览已打开时，关闭动作等待 500ms，以便同键双击改为进入编辑。焦点位于版本结构卡时，单击仍打开对应来源画布。
- 在详情预览中，500ms 内双击同一 Backquote 键：图像进入单图编辑器；可编辑文档/文本进入正文编辑。编辑中再次双击退出，正文有改动时自动保存；图像编辑器的单击关闭仍保留（未保存时沿用确认提示）。列表、首页和画布列表中的单击导航保持原行为。
- 在详情画布中选中一个或多个图像/视频后按 `F`，全屏 Coverflow 只浏览已选素材；`←` / `→` 切换素材，`F` 或 `Esc` 关闭。
- 在全屏 Coverflow 中，`←` / `→` 浏览上一张/下一张；500ms 内双击 `·`、`` ` ``、`~` 或 `Backquote` 才进入当前图片编辑器，单击不进入；`F` 或 `Esc` 关闭全屏浏览。
- 同一键在首页会进入活动项目，在项目中心会打开影视工坊，在画布列表会打开选中画布；请以当前页面和焦点为准。

## 5. 素材详情、视频和单图编辑

### 详情预览

素材详情打开时，`←` / `→` 浏览上一项/下一项；详情画布含多个对象时，这两个键改为切换画布对象。`Space` 在视频或音频预览中切换播放/暂停；图片预览不会因空格播放。`Esc` 关闭详情预览；浏览器全屏模式下，浏览器可能先退出全屏。

### 视频详情

焦点不在输入框或按钮等交互控件时：

| 按键 | 作用 |
| --- | --- |
| `A` / `D` | 后退/前进一帧 |
| `I` / `O` | 设置入点/出点 |
| `X` / `C` / `Z` | 降低播放速度/提高播放速度/重置播放速度 |
| `F` | 切换视频全屏 |
| `Enter` | 进入视频全屏 |
| `Space` | 播放/暂停视频或音频 |
| `Ctrl/⌘+C` | 复制当前视频帧 |
| `Ctrl/⌘+Shift+C` | 导出当前视频帧 |

其中无修饰键的 `C` 调高播放速度；带 Ctrl/Command 的 `C` 复制当前帧。动作只在视频详情适用。

### 单图编辑器

单图编辑器打开且焦点不在文字输入框时：

| 按键 | 作用 |
| --- | --- |
| `Q` / `B` / `E` / `C` / `T` | 切换选择、画笔、橡皮擦、裁剪、文字工具 |
| `Shift+N` | 新建画笔图层 |
| `+` / `=` / 数字键盘 `+` | 增大画笔/橡皮擦宽度 |
| `-` / 数字键盘 `-` | 减小画笔/橡皮擦宽度 |
| `Enter` | 应用当前裁剪草稿 |
| `Delete` / `Backspace` | 删除选中的图层 |
| `Ctrl/⌘+G` | 编组 |
| `Shift+G` | 取消编组 |
| `Esc` | 退出编辑器；如有未保存内容，按界面提示处理 |
| `·` / `` ` `` / `~` / `Backquote` | 双击退出编辑器；单击仍关闭图像编辑器，未保存内容沿用确认提示 |

文字输入状态下，`Esc` 先取消当前行文字编辑，不会越过输入框继续触发编辑器快捷键。

### 详情画布对象

素材详情画布含对象或批注时，`Ctrl/⌘+A` 全选对象，`Ctrl/⌘+Z` 撤销，`Ctrl/⌘+G` 编组，`Shift+G` 取消编组，`Delete` 删除所选对象。`Ctrl/⌘+C` 在视频详情中复制视频帧，在详情画布中复制所选对象。

## 6. 制片、工作流与任务页

### 制片工作流

- 在制片工作流中按 `·`、`` ` `` 或 `Backquote`：有聚焦素材时打开该素材详情；没有聚焦素材时返回项目中心。输入框、弹窗和中文组字期间不会触发。
- 在制片阶段导航条上，`←` / `→` 切换前/后一个阶段，`Home` / `End` 跳到第一个/最后一个阶段；当前必须有活动工作流。
- 项目名、画布名、工作流或文件夹重命名时，`Enter` 保存，`Esc` 取消编辑。
- 资产目录等路径设置字段中，`Enter` 保存当前路径。

### 其他标签页

当焦点位于对应标签时：

| 页面 | 按键 | 作用 |
| --- | --- | --- |
| 任务中心观测视图 | `←` / `→` | 切换相邻视图标签 |
| 任务中心观测视图 | `Home` / `End` | 切换首个/最后一个视图标签 |
| 治理页面标签 | `←` / `→` | 切换相邻标签 |
| 治理页面标签 | `Home` / `End` | 切换首个/最后一个标签 |

## 7. 弹窗、收集面板与分享批注

### 弹窗与面板

- `Esc` 关闭最上层允许关闭的浮层或弹窗。详情预览、批量选择和文字编辑可能先消费 `Esc`，所以按一次只处理当前层的动作。
- `Tab` / `Shift+Tab` 在模态弹窗内循环移动焦点，不会把操作穿透到背景页面。
- 收集素材面板中，`Esc` 关闭面板并把焦点还给触发按钮；焦点位于拖放区时，`Enter` 或 `Space` 打开文件选择器。
- 按钮和键盘按钮用 `Enter` 或 `Space` 激活。链接和浏览器原生控件沿用浏览器自身的键盘行为。

### 分享审阅的画面批注

当焦点在画面批注区域且当前分享权限允许评论时：

| 按键 | 作用 |
| --- | --- |
| `←` / `→` / `↑` / `↓` | 移动键盘批注位置，每次移动约画面宽/高的 2% |
| `Shift+←` / `Shift+→` / `Shift+↑` / `Shift+↓` | 较大步长移动，约画面宽/高的 10% |
| `Enter` / `Space` | 放置标记；矩形/自由绘制批注中，第一次设置起点，调整后再次完成批注 |
| `Esc` | 取消正在绘制的批注 |
