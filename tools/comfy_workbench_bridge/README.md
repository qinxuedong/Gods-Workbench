# ComfyUI 工作流浏览器桥

适配源码属于神工坊项目。配置本地 ComfyUI 安装根目录后，点击“导入 ComfyUI”，工作台自动将本项目 JS 提供到宿主已有前端的 `extensions/gods_workbench/workbench.js`。
无需手动安装、pip、自定义节点或重启宿主。使用 ComfyUI 官方 `app.registerExtension` 入口；不改写核心前端，不依赖旧 `rh_auto_bridge`。同名文件内容不同则保留原件并返回冲突，不覆盖。

先用神工坊右上角 CF 开关启动本地服务并等待确认运行，再点击工作流页“获取并解析”右侧的“导入 ComfyUI”。扩展加载当前原生图并确认结果；“回存神工坊”按钮按打开时的文档版本保存。CF 只负责启停，导入按钮不会隐式启动服务。
并发编辑返回版本冲突，保留 ComfyUI 中的图；重新从神工坊打开最新版本后再处理。
30秒未收到回执时解除按钮锁并显示“回存未确认”；先核对神工坊文档版本再决定重试。不会自动重发，旧请求的迟到回执不会解锁新请求。
窗口来源、ComfyUI origin 和单次随机 nonce 必须匹配。扩展不接收账户 Cookie、令牌或密钥，回存由原神工坊页的受保护接口执行。

上传普通原生 JSON 即可，节点、连线及参数保留原文。解析优先使用源图信息和主体/端点隔离的真实定义缓存；服务已经在线时可直接查询 object_info，不打开宿主页、不自动启动。内部适配仍无法确定结构时，才最后使用宿主页面的实际 graphToPrompt 并自动 CAS 回传一次。离线保留原图、提示可启动 CF 后继续，不要求用户预先导出 API，不猜图。
PNG/WebP 内嵌的完整 workflow 或 API prompt 支持本地上传、画布拖入和点击解析读取剪贴板图片。剪贴板只有在保留元数据时才能恢复；无图元数据或只有文字提示词时明确拒绝，不从像素猜测。
关闭原神工坊页或登出会结束会话；30秒未收到载入回执显示未确认，不能据写盘或打开网页宣称载入成功。
仓库测试覆盖消息合同和隔离浏览器宿主；实际 ComfyUI 安装、前端版本与缺失自定义节点仍须现场验收。

参考：[ComfyUI 官方 JavaScript 扩展](https://docs.comfy.org/custom-nodes/js/javascript_overview)。
